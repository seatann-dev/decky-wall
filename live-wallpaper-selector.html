How to use
  1. Open this page in a Chromium browser — Chrome, Edge, Brave, or Vivaldi — on the Bazzite desktop. Firefox will not work (Bazzite ships it by default, but it lacks the File System Access API this tool needs). The folder pickers only see the machine the browser runs on.
  2. Wallpaper Engine folder… → pick the Workshop folder named 431960 (that number is Wallpaper Engine’s Steam app ID — Steam names the folder after it).
  3. Plugin folder… → pick your installed Live Wallpaper plugin folder.
  4. Pick a wallpaper below → Use this, then reload Decky on the handheld.

Limitations
Only Video and Web wallpapers are supported. Scene wallpapers (Wallpaper Engine .pkg puppets) are not — they need Wallpaper Engine’s own renderer. Scene support may come in a future update. Videos embed whole, so keep them small — under ~40 MB (compress large ones with ffmpeg).
